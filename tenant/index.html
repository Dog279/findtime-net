What it is

A Go-native agent built on the Model Context Protocol: a planner that calls tools, a layered memory that learns from interaction, first-party plugins built in, and every surface you need to drive it, in one statically linked, CGO-free binary.

Bring your own model

Ollama, llama.cpp, vLLM or any OpenAI-compatible server; OpenAI, Anthropic, Z.ai, xAI, Sakana, or the Claude Code CLI. Switch with one command, mix per helper, fall back automatically.

A memory that learns

Working set, episodes, distilled facts, skills and an append-only archive. Context compaction is reversible and auditable. A soul you own defines who the agent is.

Safe by default

Tools read by default. Commands, writes, sends and irreversible actions wait for your OK, per surface, with per-tool rules and an execution sandbox. A Security log that can't be cleared.

Extend it with MCP and skills

Connect remote MCP servers with a browser sign-in, run local ones out of process, trust each one explicitly. Teach it with Agent Skills packages it versions and trusts.

Helpers and research

Five specialists ship in the binary: Programmer, Researcher, Writer, QA, Strategist. Deep research fans out and returns a cited report. A goal loop keeps working until a judge says it's done.

Runs 24/7, nothing lost

A background service with a web dashboard. Reboots cut a turn safely and the agent picks it up when you say continue. One-file backups, retention per data class, verified updates with rollback.

Drive it from anywhere

The same agent, memory and approvals behind every surface.
