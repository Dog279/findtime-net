The menu groups the pages. On a phone, **Menu** at the top opens it; **Log out** is at its bottom. "Asks first" means the button opens a second step that says what will happen, with **Yes** to go ahead and **Cancel** to back out.

| Page | Path | What it is for | Asks first |
|---|---|---|---|
| **Overview** | `/` | how the agent is (an alert, a model it cannot reach), what is waiting for you, what it may do, the services it is connected to; its model and quality score once they have data | nothing |
| **Chat** | `/chat` | talk to the agent; the page opens with the last 20 exchanges; the answer appears as it is written and settles rendered from Markdown (headings, lists, code, tables); an image in an answer shows as a link with its description, never as a picture, so the page fetches nothing an answer names until you follow the link; each tool call is a card you can open to what was asked and what came back, with a link into Logs; when the agent answers with a component (a table, a checklist, buttons for the next step, a small form) it is drawn in place of the card and again when the page reloads; a tap or a Send starts your next turn and that message is marked "via choices" or "via form"; a form whose call is gone after a restart says so and sends nothing; **Show activity** opens a rail beside the chat with what the agent is doing as it happens (each tool call and result, the judge's checks, a compaction, an error), the same lines the terminal app's feed shows, the last 200 kept; on a phone it sits below the chat; its requests for your OK appear above the message box; a `thinking…` row counts up while it answers | nothing; **Stop** is immediate |
| **Autopilot** | `/goal` | a `/goal` started from the terminal UI; **Stop after this step** | nothing |
| **Logs** | `/logs` | everything the agent and Tenant do, newest first: filters, saved views, **○ live**, an event's detail and timeline ([Logs &amp; alerts](/tenant/docs/dashboard/logs)) | **Clear** a log; **Reveal** shows a hidden value and is recorded; the Security log can never be cleared |
| **Memory** | `/memory` | what the agent knows about you: facts with provenance and history, the soul, the user profile, **Recently removed** with restore | nothing |
| **Skills** | `/skills` | induced skills waiting for review, trust decisions, auto-accept | **Dismiss**, **Remove**, **Trust**, **Choose On**, **Choose Trusted** |
| **Quality** | `/eval` | eval scores over time; run a check; the Quality model (who grades the checks) | nothing |
| **Research** | `/research` | start, watch and stop a deep-research run; past reports | **Stop** a run, **Delete** one |
| **Tools** | `/tools` | every tool, **All on** / **All off** for the acting ones, tool rules | **All on**, a rule that lets a tool go ahead, removing a rule that made a tool ask or blocked it |
| **Helpers** | `/agents` | the specialists, each with its model and instructions | **Remove**, **Reset**, **Clear instructions** |
| **Remote services** | `/mcp` | MCP connectors: connect, trust, reconnect, disconnect | **Disconnect**, **Don't ask** |
| **Scheduled jobs** | `/cron` | cron jobs with preset schedules or a typed cron line, run now, enable, the exec switch | **Delete** a job; turning on **Scheduled jobs may make changes** |
| **Fleet** | `/fleet`, `/fleet?group=<name>`, `/fleet/<id>`, `/fleet/group/<name>` | the machines this Tenant is the master of ([Fleet](/tenant/docs/fleet/machines)): on a Tenant with no fleet, **Set up the fleet** makes it a master (the fleet port's address and the addresses machines dial; everything but the recovery key, which is made at a terminal: [Set up a fleet](/tenant/docs/fleet/setup)), and a fleet without a recovery key says so; which process holds the fleet; each machine's state (waiting for you, online, offline, paused, revoked), last call, memory (in step, behind, needs recovery key, unknown) and approval settings, with what the machine reported about itself (system, account, version, sandbox, its own limit) shown in quotes as its own words; **Add machine** takes a name, and **Make a code** answers with the line to paste on the new machine and a **Copy** button, shown that once; the fleet's defaults for new machines, each category as Ask, Allow, Deny or **From this Tenant** (what this Tenant's own setting gives now), and the fleet's rules ([Fleet approvals](/tenant/docs/fleet/approvals)); groups: make one, open its page to add or take out machines and rules, **Apply** it to its members, delete it, and narrow the list to one group; tick machines, or choose everyone shown, and make one change to all of them (a category, a rule, apply the fleet's rules, copy again, or update), answered with "Done on 5 of 7." and a line for each machine not changed, with why; a rollout that updates many machines 1 to 8 at a time, with **Stop** ([Fleet updates](/tenant/docs/fleet/updates)); a machine's page confirms it with the six digits it shows, in a browser signed in on the computer running Tenant at its 127.0.0.1 or localhost address, or in a signed-in browser elsewhere with the sign-in key again once remote confirmation is turned on at the master's terminal ([Set up a fleet](/tenant/docs/fleet/setup#confirming-from-another-computer)); its permissions and rules, with the same controls and words as **Approvals &amp; safety** and **Tools**, compared with a fresh copy; the groups it is in; **Update** to a newer Tenant; **Rename**; revoke. The defaults, the groups, changes to many machines and rollouts take a signed-in browser, never the API key | **Allow** for an area or **Don't ask** on a rule, removing a rule that made it ask or blocked it, **Copy again**, **Apply fleet rules**, **Update this machine**, **Revoke, keep its settings**, **Revoke and delete**, **Delete its record**; a default of **Allow** or **From this Tenant**, an allow rule in the fleet's defaults, deleting a group, a group's **Apply**; for many machines, any change that lets the agent do more, **Apply**, **Copy again** and **Update**, on a step page that names how many machines and which, and those left out and why. A rule added to a group asks nothing, since it moves no machine until the group is applied. **Ask**, **Deny**, a block rule and **Stop** go through at once. Confirming has no second step: typing the machine's six digits is the step |
| **Approvals &amp; safety** | `/safety` | what is waiting for your OK; what the agent may do on its own ([Approvals](/tenant/docs/dashboard/approvals)) | **Allow** for an area, **Allow for the rest of this session**, a pairing's **Allow once** |
| **Access** | `/access` | who may message the agent on Discord and iMessage and what those conversations may make it do ([Access](/tenant/docs/dashboard/access)) | **Add someone**, **Remove everyone**, removing the last person, **Turn on** / **Start**, changing the approving Discord account, letting Discord run commands, **Allow** for an area |
| **Model** | `/models` | which model answers and whether it can see images; add a server on your network or a cloud model; the loop ceiling, the repeat guard and the [judge](/tenant/docs/models/judge) (kind, server, key, model, rounds, on or off); **Reload API keys** | **Use this model**, **Remove** |
| **Integrations** | `/integrations` | Google, Atlassian, GitHub and the others: save, test, disconnect; GitHub repositories and their write mode | **Disconnect**, **Allow changes** on a repository |
| **Provider keys** | `/settings/keys` | the API keys, write-only; a new key for the model in use applies on **Reload API keys** | **Remove** |
| **Settings** | `/settings` | the rest | |

**Busy.** While the agent answers a Chat message, the line under every page title says "Your agent is answering a message", with **Stop**. Scheduled jobs, Discord and iMessage conversations and alert checks run alongside and never hold up Chat. A second message sent while it is answering is not sent and stays in the box.

**Live updates paused. Reload the page to see new requests.** The page lost its connection to Tenant (a restart, or the network dropped). Reload.

Every page is also reachable by its path, so a bookmark to `http://127.0.0.1:9770/safety` opens straight to approvals after sign-in.
